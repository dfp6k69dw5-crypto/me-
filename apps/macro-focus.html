Native iPhone camera experiment

MACRO
FOCUS

One job: make very small, very close things sharp. The native build biases autofocus toward nearby subjects and gives you a dedicated HUNT control when normal autofocus gets distracted by the background.

NEAR FOCUS · READY

Why this one is native

The near-focus behavior uses direct iPhone camera controls that a normal GitHub Pages web app cannot reliably access. The source is stored here in the repo and is ready to be built as an iPhone app.

Current controls

Near-range autofocus preference, tap-to-focus, continuous refocusing, lens-position feedback, animated focus reticle, HUNT mode, and full-resolution photo capture.
