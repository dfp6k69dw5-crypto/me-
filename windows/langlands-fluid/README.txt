LANGLANDS FLUID — AMBIENT WINDOWS

START
1. Keep this folder together.
2. Double-click: Start Langlands Fluid.cmd
3. Microsoft Edge opens the local fluid app in fullscreen kiosk mode.
4. No internet connection is required after this folder is downloaded.

USE
- Auto: the fluid runs and morphs by itself. Mouse drawing is ignored so accidental movement does not disturb the screensaver.
- Hybrid: it keeps running and morphing, but you can draw/stir with the mouse too.
- Manual: autonomous morphing/emission stops; you control the fluid yourself.
- Move the mouse to reveal controls. They hide again after the selected delay.
- New journey reseeds the autonomous system and starts a new evolving path.
- Calm ↔ wild changes how aggressively the autonomous system explores.
- Morph speed changes how quickly parameters drift.
- Emitters changes the number of autonomous dye sources.

EXIT
Press Alt+F4 to close the fullscreen Edge window.

NON-LOOPING BEHAVIOR
This is not a prerecorded animation or fixed timeline. Parameters wander toward changing stochastic targets, emitters drift with randomized dynamics, and rare events occur at irregular intervals. There is no designed return point or loop boundary.

WINDOWS POWER SETTINGS
This behaves like an ambient fullscreen screensaver, but it does not override Windows power management. If Windows is configured to turn the display off after a short time, the display may still turn off.
